JFX Site Scraper
JFX Site Scraper — это настольное приложение, разработанное на Java с использованием JavaFX, предназначенное для выполнения HTTP GET-запросов и парсинга/отображения полученного содержимого веб-страниц.
Для кого: Проект предназначен для разработчиков, тестировщиков, или специалистов по SEO/анализу данных, которым требуется быстрый и визуальный инструмент для инспекции контента, возвращаемого веб-серверами (например, для проверки API-ответов, отладки заголовков или простого извлечения HTML-кода).
Основные функции:
-Простой графический интерфейс (GUI) для ввода URL.
-Выполнение асинхронных HTTP GET-запросов.
-Отображение полного содержимого ответа (включая заголовки и тело) в удобном текстовом поле.
-Обработка и вывод ошибок HTTP-соединения.
Проект использует Maven для управления зависимостями и сборки.
Требования к среде
Убедитесь, что у вас установлен JDK версии 17 (или выше).
Шаг 1: Клонирование Репозитория
Сначала склонируйте репозиторий на свой локальный компьютер:
bash
git clone https://github.com/ВашПрофиль/JFX-Site-Scraper.git
cd JFX-Site-Scraper
Шаг 2: Сборка Проекта с Maven
Используйте Maven для загрузки всех необходимых зависимостей (включая JavaFX) и компиляции кода:
bash
mvn clean install
Шаг 3: Запуск Приложения
Запуск приложения с использованием настроенного Maven-плагина для JavaFX:
bash
mvn javafx:run
Приложение должно запуститься с главным окном, предлагающим ввести URL.
Примеры Использования
После запуска приложения, вы увидите простое окно с полем ввода URL и кнопкой “ПОЛУЧИТЬ СОДЕРЖИМОЕ”.
Пример 1: Запрос к тестовому API (JSON-ответ)
В поле ввода введите: https://jsonplaceholder.typicode.com/posts/1
Нажмите кнопку “ПОЛУЧИТЬ СОДЕРЖИМОЕ”.
В поле вывода появится чистый JSON-ответ.
Пример 2: Запрос к простому HTML-сайту
В поле ввода введите: https://example.com
Нажмите кнопку “ПОЛУЧИТЬ СОДЕРЖИМОЕ”.
В поле вывода отобразится полный HTML-код страницы.
